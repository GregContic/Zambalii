# Zambalii Grill image library

Drop the restaurant's approved images into the folders below. The website's image paths are centralized in `src/data.js`, so replacements only need to keep the filenames (or update that one file).

- `hero/` — the main restaurant or food image used in the hero (`hero-main.jpg`)
- `food/` — BBQ, grilled dishes, soups, rice meals, and featured dishes
- `restaurant/` — interior, exterior, dining area, and ambiance photos
- `gallery/` — general restaurant, customer experience, and additional food photos
- `logo/` — restaurant logo and alternate versions
- `icons/` — custom icons or decorative assets

The current website uses descriptive filenames such as `hero-main.jpg`, `grilled-pork-rice.jpg`, `dessert-special.jpg`, `restaurant-interior.jpg`, and `logo-wall.jpg`. Until more photos are added, any missing local image falls back gracefully to temporary demo photography.
